# 1.0.3

## 扫描

- 识别到的二维码指示器**明显放大**，更容易看清和点中。
- **识别到多个二维码时，画面会静止**。此前指示器画出来了，但预览还在动，手机一移指示器就偏到二维码外面；现在冻结识别所用的那一帧，指示器稳定停在二维码上，**点哪个就识别哪个**。
- 一帧里识别到的**多个二维码现在全部记入历史记录**（此前只记录其中一个，其余在画面移走后丢失）。
- 修复切换标签时的**画面闪烁**：离开扫描页会释放相机，返回时恢复（这是你要求的行为，我按原样恢复了）。
- iOS：**扫描界面现在也有绿色指示器**，多码选择与安卓完全一致（此前 iOS 不上报位置，所以一个指示器都没有）。
- iOS：修复**首次授权相机后黑屏**。相机启动现在会校验是否真的启动、失败自动重试，持续失败会显示提示与「重试」入口，不再是一片黑。

## 生成

- 点击**粘贴 / 生成 / 清空**时自动收起键盘。此前输入法不退出，在小屏手机上会挡住刚生成的二维码。
- 小屏手机（如 iPhone SE 一代）上三个按钮的**文字不再折行**竖排。

## 更新

- **网络无法访问 GitHub 时，更新检查与下载会自动改用镜像**，原始地址保留为兜底。

## 安装

| 平台 | 产物 |
|---|---|
| Android | `wechatqr-1.0.3-arm64-v8a.apk` |
| iOS | `wechatqr-1.0.3.ipa`（由手动工作流产出，供 TrollStore 安装） |

Android 仅支持 **arm64-v8a**：应用内置的 OpenCV 运行库只有这一种架构，其他架构的包装上后会无法识别。

## 说明

iOS 的 ipa 不属于本版本 tag 自动产出的一部分 —— 它需要单独触发一次 `iOS build (manual)` 工作流并附加到本 Release。在那之前，下面的资产里只有 Android 的 APK。
